# Thus spoke Zakura

I want to make a project called "thus-spoke-zakura", the goal is to create a regtest based dev environment, where the user just enters a single command, and they have working zcash regtest dev environment up and running for them.

The goal is superior DX for developers

We also need a working block explorer here for this regtest that ships with it.

The user types:

"thus-spoke-zakura", boom it starts a zakura based regtset on free ports for the user, with a block explorer as well, we also need a web based zcash wallet shipped with this as well, where the web-wallet has 5 accounts that they can transfer zcash between to test the network deployed, + we also need the ability to faucet with these wallets.

Optimize for the cleanest, and the best UX possible here.:w


NOTE: we want to use zakura and zakura common based code and libraries to build or software -> https://github.com/zakura-core/common
